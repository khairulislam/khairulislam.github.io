This course covers the current state and future trends in hardware and software for Big Data Systems and applications. Our overarching goal is to build efficient software and hardware for big data processing, analytics and machine learning at scale. Core topics covered include distributed data processing, cloud-scale ML pipelines, and automated feature engineering, using AWS SageMaker and S3. Course instructor: Professor Judy Fox. The course website is here: [UVA-MLSys/Big-Data-Systems](https://github.com/UVA-MLSys/Big-Data-Systems).
